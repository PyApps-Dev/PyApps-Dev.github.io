**Pulsar Bank** est une simulation d'application bancaire moderne et sécurisée développée en Python avec une interface graphique **CustomTkinter** et une intégration backend **Supabase**.

---

## ⚠️ ATTENTION ⚠️ 

⚠️ **Avertissement important :** Pulsar Bank est un projet de démonstration et une simulation logicielle open-source.
**Ce n'est pas une véritable banque** et la plateforme ne fournit aucun service financier réel. Tous les soldes, transactions et opérations sont purement fictifs.


---

## 🚀 Fonctionnalités Principales

- 🔐 **Authentification Sécurisée** : Connexion et gestion des utilisateurs via Supabase.
- 💳 **Générateur de Cartes Virtuelles** : Cartes bancaires virtuelles personnalisées avec rendu dynamique.
- 📲 **Système de Recharge QR Code** : Rechargement rapide et simulation de paiement par QR Code.
- 📊 **Tableau de Bord interactif** : Suivi du solde, historique des transactions et gestion des dépenses.

---

## 🛠️ Stack Technique

- **Langage** : Python 3.10+
- **Interface Graphique** : CustomTkinter / Tkinter
- **Base de Données & Auth** : Supabase
- **Génération Graphique** : Inkscape / SVG / QR Code API
